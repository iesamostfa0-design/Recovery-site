# تعافي

«حياتك تستحق... ابدأ من جديد.»

تطبيق عربي (RTL) يعمل بدون حسابات وبخصوصية عالية، وبياناته الشخصية محلية على جهاز المستخدم. مبني بـ HTML + CSS + JavaScript فقط.

## التشغيل في Acode

1. ضع مجلد `tafafi` كاملًا في التخزين الداخلي وافتحه في Acode.
2. شغّل `index.html` بزر المعاينة (يجب أن يكون عبر خادم Acode المدمج وليس بفتح الملف مباشرة، لأن التطبيق يقرأ ملفات `data/*.json`).
3. بعد أول فتح مع الاتصال يعمل التطبيق بدون إنترنت.

## هيكل الملفات

```
tafafi/
├── index.html            الصفحة الوحيدة (الهيكل + النوافذ)
├── sw.js                 العمل بدون إنترنت (Service Worker)
├── css/
│   ├── variables.css     الألوان والمسافات والوضع الداكن وحجم الخط
│   ├── base.css          الأساسيات
│   └── components.css    المكونات
├── js/
│   ├── config.js         الإعدادات والتنقل
│   ├── utils.js          أدوات (تهريب النصوص، التواريخ)
│   ├── storage.js        التخزين المحلي + تصدير/استعادة/حذف
│   ├── prefs.js          المظهر وحجم الخط
│   ├── content.js        تحميل المحتوى من data/ وتحديثه
│   ├── ui.js             إشعار، تأكيد، نافذة، ربط أحداث
│   ├── outbox.js         صندوق الرسائل المحلي (تعليقات/اقتراحات/دعم)
│   ├── journey-store.js  بيانات رحلتي (محفزات، عادات، أهداف، تقدم)
│   ├── router.js         التنقل (#/tab/page/...)
│   ├── app.js            بدء التطبيق ونافذة المساعدة
│   └── views/            home, journey, knowledge, events, games, more, sections
└── data/                 كل المحتوى (JSON) ويُحدَّث دون تعديل الكود
```

## تحديث المحتوى دون تعديل الكود

- مقالات: `data/articles.json` (الحقل `category`: `health` | `articles` | `religion`).
  لا تُعتبر المادة معتمدة حتى تضع `"reviewed": true`؛ قبلها تظهر بشارة «مسودة قيد المراجعة».
- فيديوهات: `data/videos.json` (روابط `https://` فقط).
- تحديات: `data/challenges.json`، فعاليات: `data/events.json` (التاريخ `YYYY-MM-DD`).
- هوايات وأسئلة شائعة وخصوصية وألعاب: ملفاتها في `data/`.
- عند إضافة ملف جديد للمشروع: أضفه إلى `SHELL` في `sw.js` ورفّع رقم `CACHE`، وأضفه إلى `files` في `js/content.js` إن كان ملف محتوى.

## ملاحظات مهمة

- الرسائل والتعليقات والاقتراحات تُحفظ على الجهاز فقط ولا تُرسل لأي جهة حتى يُفعَّل `Tafafi.config.api` مع خدمة إشراف (مرحلة مستقبلية).
- لا يحتوي المشروع على نصوص دينية؛ يُضاف المحتوى الديني من جهة مراجِعة فقط.
- مقالات الصحة الحالية مسودات تحتاج مراجعة مختصين قبل اعتمادها.
- لا توجد أرقام طوارئ مضمّنة لأنها تختلف من بلد لآخر.
